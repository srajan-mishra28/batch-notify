# Batch Notify

Holds notifications and releases them in batches every 3, 4, 6 or 12 hours.

## Run on your phone
1. Open this folder in Android Studio.
2. Wait for Gradle sync.
3. Plug in your phone (USB debugging on) and press Run.

## Get an APK without Android Studio
Push to GitHub. The "Build APK" action builds it.
Download it from the Actions tab, under Artifacts.
